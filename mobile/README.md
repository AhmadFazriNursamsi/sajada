# React Native starter
Separate Expo app, not a WebView. Demonstrates home, product browsing, cart removal and demo checkout. State is session-only. No APK/IPA was generated or device testing performed.
Run npm install, then npm start in this folder in a supported local Node/Expo environment. Validate SDK/device compatibility and dependencies before real deployment. Configure real application identifiers before release.
Next work: OIDC authorization code with PKCE and secure token storage, TanStack Query API cache, shared typed API contracts, React Navigation, offline request queue/idempotency, push notifications, and tenant membership selection. Never embed database credentials in this app.
